# Dados

O pipeline utiliza o corpus HateBR, disponibilizado pelo projeto oficial em https://github.com/franciellevargas/HateBR. O arquivo esperado é `data/HateBR.csv`; o script tenta baixá-lo automaticamente quando ele não existe.

O corpus contém linguagem ofensiva e deve ser utilizado respeitando sua licença e finalidade de pesquisa. Não inclua tokens, chaves de API ou credenciais no repositório.
